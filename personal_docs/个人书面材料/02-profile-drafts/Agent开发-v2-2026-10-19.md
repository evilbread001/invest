### 1. 产线制程诊断 Agent：确定性诊断与大模型协作

**项目背景：** 制程异常排查依赖专家经验和跨系统人工查数，诊断效率低、经验难复用，需建设适配多产品、多产线的诊断 Agent。

**成果与收益测算：** 按 **10 家客户、40+ 条产线、20+ 个工艺场景**的应用规模测算，预计平均每家客户每周净节省约 **18 人时**的异常分析与报告整理投入。

**主要工作：**
- **诊断流程与分析开发：** 基于 BPMN 和故障树执行器开发工单诊断流程，支持自动分析、人工检查与等待恢复；封装 **3σ 判异、共性分析等**函数，关联生产与质量数据，替代重复查数和手工比对。
- **大模型辅助排查：** 开发树外问题的对话式协作原型，结合工单证据生成补充排查建议；将工程师反馈转为结构化诊断记录，生成报告草稿及故障树补全建议，由人工确认结论。
- **LLM 自动建树：** 基于 DSH、Skill 与 Tool Calling 开发知识提取和对话编辑能力，将 8D、历史工单、FMEA 转为故障树草稿；联动可视化编辑器，打通自然语言修订、草稿保存、校验反馈与人工发布流程。

### 2. 多模态售后客服 Agent 与 RAG 知识库

**项目背景：** 面向教育硬件售后，将分散的服务知识用于自动答疑、故障指引与派单信息采集，减少重复咨询转人工。

**项目成果：** 系统内部模拟评测拦截率由约 **13% 提升至 55%**，评测基于 **1000 条真实线上会话**构建；项目处于内测阶段，拦截率口径为未选择转人工的会话占比。

**主要工作：**
- **RAG 知识库建设：** 从 0 到 1 搭建知识卡入库、向量化与增量更新链路；基于 PostgreSQL / pgvector 实现四字段向量与字面**八路召回、加权 RRF 融合**，支持 Cross-Encoder 重排、低分过滤及产品范围筛选。
- **召回与评测优化：** 编写脚本批量调用大模型，参考真实用户问法扩充相似问题，改善口语表达与知识术语不匹配的问题；参与模拟回归及 Bad Case 分析，定位召回、工具调用和字段采集问题，推动知识与 Skill 迭代。
- **业务 Skill 开发：** 基于 DSH 开发故障分流与派单采集 Skill，结合 VLM 识别的 SN 和故障线索，实现多轮字段提取、缺失项追问、多设备信息补齐及共享字段复用。

### 3. 压装曲线多策略判异与边缘监测

**项目背景：** 压缩机压装质量检测依赖终值和固定判异框，难以识别过程形态异常，且人工调整边界成本高。

**项目成果：** 覆盖 **3 条线体、9 个压装点位**，平均准确率提升至 **99.5% 以上**；申请发明专利《一种基于LSTM的压装工艺质量的曲线模型判异方法》（**第二发明人，已通过初步审查**）。

**主要工作：**
- **统计与特征判异：** 结合拐点、极值识别与 **3σ 标定**优化判异框；将曲线划分为 **5 个阶段**，提取峰谷值、斜率、面积等特征，使用孤立森林识别局部阶段异常。
- **深度序列建模：** 基于 PyTorch 开发 **LSTM 自编码器**，完成正常压力—位移曲线的长度统一与训练，以重构误差识别整体形态异常，与统计规则及分段特征方法互补。
- **边缘部署：** 打通曲线解析、预处理、推理与异常推卡链路，关联曲线和零件信息支持现场人工复判与追溯。
