# BPMN/OWL 本地接入方案与实施清单

目标：保留已确认的三栏交互，用原 lads 引擎执行原 PCBA 少锡流程。DSH 仍只能读状态、解释和创建待确认提议。

边界：不修改原仓库，不加载其环境变量，不访问数据库/ETCD/MES/FTA，不推卡、不控线。模型权限与执行引擎独立。

实现：Node 每次通过 stdin 向独立 Python 进程发送上一份引擎快照及已确认反馈。Python 导入原 `run_bpmn`、`fault_tree_diagnosis`、`OWLExecutor`、恢复器及 TODO 生成器，读取原 `diagram.bpmn` 和 `make_owl_new.py`。基础设施适配只在子进程中生效：快照在内存交接、生产推送禁用、检测标准取本地 CSV。返回的新引擎快照和领域状态共同原子写入同一工单 JSON，避免双存储失配。

加载方式：用命名空间包指定源目录，跳过带有环境初始化副作用的包门面；实际执行模块保持原文件。远程存储/取数/推送替换为显式本地适配，不替换路由求值或等待/恢复逻辑。进程禁止网络连接及创建外部进程；Node 不向其传递模型 Key。

自动分析：未接 MES 的 UDF 不执行生产实现。树上明确支持“分析不可用”的条件返回该状态并标注；其余 UDF 请求显式的离线分析结果，不能以缺数据冒充正常。感知和 NLP 节点使用合成少锡事件；报告输出诊断路径，不回写生产 8D。

实际发现的边界：本地 CSV 并不覆盖当前树的全部 TEST，缺项时从树 expected 条件推导离线选项并加警告，不冒充已审核标准。原 OWL 将 NTF（未发现故障）和执行异常均返回 FAILED；适配层仅将精确 NTF 归一化为已结束但未得结论，清空伪根因，其他失败一律阻断提交，避免被 BPMN 默认分支误当成功。没有修改原推理算法。

交互：卡片从真实执行队列生成，用执行 ID 绑定反馈，选项取原标准。未知/暂缓保留为未回答，不写正常。原引擎串行支路不允许任意调整顺序，接口明确拒绝，不用 UI 假装已改路由。源码版本变化拒绝恢复旧快照。根因命中只展示为树推断，仍需工程师确认。

## 2026-10-19 协作层扩展

- 从快照 `dep_graph` 读取带作用域的 TEST 目录。仅当前等待条件所属父节点下的单一、非否定 TEST 条件允许提前登记观察；不改变原执行器。目录中的其他项可检索，但前置不足时不能派发补查。同层判定不是现场安全授权。
- 补查是独立任务：创建需确认，填报需核对板件、工况和许可；结果不会立即反馈 OWL。原树正式激活同一 conditionId 时显示既有记录，由人工再次确认复用，禁止按名称跨分支复用。
- 协作状态与快照在同一 JSON 持久化：假设、分析证据、人工验证、专家结论。批次/换料统计由确定性代码计算独立合成样本，不混同生产 UDF。
- 专家结论通过独立 `/resolution` 接口核对版本、幂等键、署名和确认声明。模型没有确认工具。确认后应用层结束诊断并冻结写入，原树快照仍可保持 Waiting；报告显式保留这个区别，不把未查项标正常。
- 专家草稿引用本工单同一假设的证据，至少包含人工验证记录；后续证据或任务变更使草稿过期。全部反对证据、口述局限与未查项仍展示，不只展示草稿选中的证据。
- `smoke-collaboration` 的三轮真实模型验收通过：暂缓＋补查提议、合成批次统计、人工验证＋专家结论草稿；最终由测试模拟人工确认，原树快照完全不变。24 项 Node 测试与 4 项 Python 测试通过。
- 浏览器工单 `PCBA-33305679` 已验证真实对话、合并补查卡、独立结果保存和专家确认表单；未署名核对时拒绝结束，署名后为“已结束·专家确认”，原焊盘任务仍暂缓、原树快照仍 Waiting。页面无错误、无横向溢出。

# 本地增量故障树版本（2026-10-19）

树外专家结论通过受限 DSH 生成任务形成 JSON 候选路径。两次人工确认后保存本地版本：原节点以基础版本内稳定序号定位，新节点使用增量 ID 派生 UUID，检查标准与双选项随版本保存；原 `OWLNode`、`RoutingRule`、`AtomicCondition` 装配并执行追加路径。不执行 LLM 生成代码，不修改原仓库。

`baseVersion` 对基础引擎及原树做指纹；增量 JSON 参与执行版本哈希。新工单绑定激活版本及增量内容，已有工单保持原快照。发版先探测可装配性、检查基础版本及父发布版本，再原子更新本地 registry；工单发布状态写入失败可按发布记录恢复。这里只追加分支，不实现生产审批、整树编辑或回滚界面。

生成步骤区分已有验证与待验证建议。证据引用属于本工单对应假设，已有验证至少引用人工报告。无法判断不能并入命中或排除选项。工程含义、适用场景和安全操作标准仍需人工核对；不是自动学习后直接上线。
