### 1. 产线制程诊断 Agent：确定性诊断与大模型协作

**技术栈：** Python、TypeScript、DSH、BPMN、故障树、SQL
**项目概述：** 面向多产品、多产线的制程质量异常，融合专家故障树、生产数据分析与工程师反馈，支持工单驱动的根因排查、处置建议与诊断追溯；按 **10 家客户、40+ 条产线、20+ 个工艺场景**的应用规模测算，预计平均每家客户每周净节省约 **18 人时**的异常分析与报告整理投入。

- **诊断流程研发：** 围绕异常工单构建“数据分析—故障树排查—人工反馈—诊断记录”链路，将不同工艺的专家排查逻辑组织为故障树与检查项，通过 BPMN 管理诊断阶段、故障树执行器计算条件和分支，衔接自动分析与人工检查；支持等待现场反馈后恢复执行。
- **自动诊断分析开发：** 将专家排查中的数据核查与统计分析步骤封装为故障树可调用的分析函数，如 3σ 判异、共性分析等；关联生产、质量检测及设备履历，将分析结果用于诊断条件判断与后续排查，减少工程师手工查询、汇总和比对数据的工作。
- **大模型辅助诊断排查：** 面向既有故障树未覆盖或标准路径无法定位的问题，设计对话式诊断协作能力，结合异常现象、历史排查结果与可用知识生成根因假设及补充检查建议，辅助工程师开展验证；将工程师自然语言反馈转化为结构化排查记录，关联检查动作、结果与证据，并基于全过程记录生成诊断报告草稿，由工程师确认结论，为后续故障树补全提供依据。
- **LLM 自动建树 Agent：** 基于 DSH 与业务 Skill 开发自动建树能力，从 8D、历史工单、FMEA 等资料中提取失效现象、原因关系、排查步骤与处置措施；设计对话式故障树编辑交互，将专家的自然语言建树与修改需求转化为结构化节点、分支及判断条件，通过 Tool Calling 联动编辑器读取当前树、保存修改草稿并调用校验。衔接“资料生成—对话修订—草稿保存—校验反馈—人工发布”的故障树生命周期，让专家在可视化树结构与多轮对话中协同完成知识构建和维护。

### 2. 多模态售后客服 Agent 与 RAG 知识库

**技术栈：** Python、DSH、FastAPI、PostgreSQL / pgvector、RRF、Embedding / Reranker、VLM  
**项目概述：** 面向教育硬件售后，支持故障咨询、排查指引、派单信息采集及转人工；当前处于内测阶段。

- **知识库建设：** 从 0 到 1 建设售后 RAG 知识库，打通知识卡建模、向量化入库、增量更新与检索服务链路；基于 PostgreSQL / pgvector，围绕标题、相似问题、故障描述、解决方案构建“四字段 × 向量/字面”的八路召回与加权 RRF 融合，支持 Cross-Encoder 重排及低置信结果过滤；结合产品适用范围筛选和已尝试方案去重，为客服 Agent 提供适配当前设备与排查进度的知识依据。
- **召回优化：** 针对用户口语表达与知识卡术语不一致导致的召回问题，通过脚本批量调用大模型，参考真实客服问法扩充相似问题并更新索引；结合实际 Query、产品过滤条件和命中卡片分析失败环节，而非仅调整向量模型。
- **业务 Skill 与多轮填单：** 围绕故障分流与派单信息采集设计 Skill，按维修/安装场景组织必填字段，从渠道信息、历史记录及对话中提取联系人、地址和设备信息；结合 VLM 提取的 SN 与故障线索，支持多设备逐台补齐、共享字段复用及缺失项追问，通过结构化工具反馈约束收集过程。
- **评测与 Bad Case 分析：** 参与基于 **1000 条真实线上会话**的模拟用户回归评测，按知识召回、工具调用、字段采集、业务流程及模拟器行为归类问题，推动知识与 Skill 迭代。系统内部模拟评测拦截率由约 **13% 提升至 55%**。

### 3. 压装曲线多策略判异与边缘监测

**技术栈：** Python、PyTorch、LSTM 自编码器、孤立森林、3σ 统计标定
**项目概述：** 面向压缩机压装过程，识别压力—位移曲线中的过程异常，补充单纯终值或固定判异框的检测局限。

- **多粒度异常检测：** 结合拐点、极值识别与 **3σ 统计标定**优化关键区间判异框；识别 **4 个关键点、划分 5 个阶段**，提取峰谷值、斜率、区间长度、面积及标准差等特征，通过孤立森林识别阶段特征异常。
- **序列模式学习：** 基于 PyTorch 构建 **LSTM 自编码器**，对正常压力—位移曲线进行长度统一与序列建模，以重构误差识别整体形态偏离；与判异框、阶段特征方法互补，降低对异常标签和单一人工特征的依赖。
- **工程落地：** 完成曲线解析、预处理、模型推理及边缘部署链路，项目覆盖 **3 条线体、9 个压装点位**，平均准确率提升至 **99.5% 以上**；采用异常推卡与人工复判方式，关联原始曲线和零件信息支持追溯。
- **技术成果：** 发明专利《一种基于LSTM的压装工艺质量的曲线模型判异方法》（**第二发明人，已通过初步审查**）。
